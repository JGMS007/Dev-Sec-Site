Nota da equipe técnica: este texto é um modelo genérico de política de privacidade, criado para servir de ponto de partida. Recomendamos que a Synergy Solutions consulte um profissional especializado em LGPD antes de publicar esta página oficialmente.

1. Quem somos

A Synergy Solutions é responsável pelo tratamento dos dados pessoais coletados através deste site, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

2. Quais dados coletamos

Coletamos apenas os dados que você nos fornece voluntariamente ao preencher o formulário de contato:

  • Nome
  • E-mail
  • Telefone (DDD + número)

Não coletamos automaticamente outros dados pessoais neste momento.

3. Para que usamos esses dados

Os dados informados no formulário são usados exclusivamente para iniciar um contato via WhatsApp com a nossa equipe, a seu pedido, para tratar sobre nossos serviços. Não usamos esses dados para nenhuma outra finalidade.

4. Com quem compartilhamos seus dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros. O envio da mensagem acontece diretamente entre o seu navegador e o WhatsApp, a partir de um link que você mesmo confirma antes de enviar.

5. Cookies

No momento, este site não utiliza cookies de rastreamento ou ferramentas de analytics. Caso isso mude no futuro (por exemplo, com a adição do Google Analytics), esta política será atualizada para refletir essa mudança.

6. Seus direitos como titular dos dados

De acordo com a LGPD, você tem o direito de solicitar, a qualquer momento:

  • Confirmação de que tratamos seus dados;
  • Acesso aos dados que temos sobre você;
  • Correção de dados incompletos ou desatualizados;
  • Exclusão dos seus dados de nossos registros.

7. Como falar conosco

Para exercer qualquer um dos direitos acima, ou tirar dúvidas sobre esta política, entre em contato pelo formulário na página inicial.
